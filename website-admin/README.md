# website-admin

Site quản trị (Next.js 16). Chạy từ thư mục `website-admin/`.

```bash
pnpm --filter website-admin dev
```

Dùng: Next.js, Zod (validate response backend), Zustand (filter state). Nội dung chung từ `@magicore/content`. Backend đang chạy ở `http://localhost:3000` (`pnpm --filter backend dev`).
